# imToken Fans 路演网页版

12 页精简正体漫画版，含两页产品展示及和平星结尾。图片与用户提供的《铁甲小宝》主题曲音轨均已内嵌，可离线播放。

## 打开

下载 [imTokenFans-roadshow.html](imTokenFans-roadshow.html)，保存到本机后用桌面浏览器打开。GitHub 文件页只展示源码，可用 Download raw file 下载；本次提交不包含网站部署。

## 操作

- 空格 / 方向键：逐步展开与翻页。
- F：全屏；N：本页讲稿；G：总览；B：黑屏。
- 第 6、10 页：「请开始你的表演」，切换产品或硬件展示。
- 第 12 页：第一次空格揭晓「现在」，第二次揭晓和平星并播放音乐。后退或离开彩蛋时停止。
- 底部「音乐 ♫」可试听、暂停或更换音源。演示前检查电脑输出音量。
