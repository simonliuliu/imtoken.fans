# imToken Fans 路演网页版

12 页精简正体漫画版，含两页产品展示及和平星结尾。图片与用户提供的《铁甲小宝》主题曲音轨均已内嵌，可离线播放。

## 打开

下载 [imTokenFans-roadshow.html](imTokenFans-roadshow.html)，保存到本机后用桌面浏览器打开。GitHub 文件页只展示源码，可用 Download raw file 下载；本次提交不包含网站部署。

## 操作

- 空格 / 方向键：逐步展开与翻页。
- P：演讲者视图（新窗口显示讲稿、本页计时与下一页，可拖到自己的屏幕；投影只放幻灯片）。
- F：全屏；N：本页讲稿（叠在画面上，单屏排练用）；G：总览；B：黑屏。
- 鼠标静止 2 秒后控制栏与光标自动隐藏，移动鼠标即出现。
- 第 6、10 页：「请开始你的表演」，切换产品或硬件展示。
- 第 3 页：三种连接逐个出现，共 3 次空格。
- 第 8 页：空格后暗场，揭晓 One more thing。
- 第 12 页：第一次空格揭晓「现在」，第二次揭晓和平星，文字逐行盖章，音乐淡入。后退或离开彩蛋时音乐淡出停止。
- 底部「音乐 ♫」可试听、暂停或临时更换音源（仅本次打开有效）。演示前检查电脑输出音量。
