# imToken Fans 路演网页版

15 页精简正体漫画版，含两页产品展示及和平星结尾。图片与用户提供的《铁甲小宝》主题曲音轨均已内嵌，可离线播放。

## 打开

下载 [imTokenFans-roadshow.html](imTokenFans-roadshow.html)，保存到本机后用桌面浏览器打开。GitHub 文件页只展示源码，可用 Download raw file 下载；也可使用下方在线演示地址。

## 操作

- 空格 / 方向键：逐步展开与翻页。
- P：演讲者视图（新窗口显示讲稿、本页计时与下一页，可拖到自己的屏幕；投影只放幻灯片）。
- F：全屏；N：本页讲稿（叠在画面上，单屏排练用）；G：总览；B：黑屏。
- 鼠标静止 2 秒后控制栏与光标自动隐藏，移动鼠标即出现。
- 第 7、13 页：「请开始你的表演」，切换产品或硬件展示。
- 第 3 页：三种连接逐个出现，共 3 次空格。
- 第 9 页：空格后暗场，揭晓 One more thing。
- 第 11 页：Agent 进入生活，先出现成熟硬件，再揭晓「替你操作手机」。右侧为多款带屏成熟硬件图。
- 第 12 页：硬件扩展许愿平台，3 次空格：痛点 → 许愿流程 → 「每个人，都能共同创造」。
- 第 15 页：第一次空格揭晓「现在」，第二次揭晓和平星，文字逐行盖章，音乐淡入。后退或离开彩蛋时音乐淡出停止。
- 底部「音乐 ♫」可试听、暂停或临时更换音源（仅本次打开有效）。演示前检查电脑输出音量。

## 在线演示

**在线演示：https://imtoken-fans-roadshow.vercel.app/**

无需登录。其他电脑用浏览器打开即可。空格逐步展开，F 全屏，P 打开演讲者视图；建议演讲前先试听电脑音量。

独立 Vercel 项目 imtoken-fans-roadshow，静态配置位于 deliverables/roadshow/vercel.json，不复用社区主站项目或环境变量。部署采用本目录文件，根路径指向同一份路演HTML；部署溯源见 deployment.json。GitHub PR更新与公开演示站发布分开记录，本次不自动合并PR。

第6页新增荣格「集体无意识」的启发与社区塑造人格的产品隐喻，资料与说明写入本页讲稿（N/P）。新增页之后的页码和结尾音乐索引已更新。旧预览图仍为14页版参考。
