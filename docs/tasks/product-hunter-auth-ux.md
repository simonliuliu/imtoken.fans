# Product Hunter 继承社区登录体验

日期：2026-10-16。分支：`codex/product-hunter-auth-ux`。状态：开发完成，本地交互回归及独立 QA 通过，待 PR review。

## 用户目标与范围

- 产品猎手共用社区的 AuthProvider、Supabase 会话与登录页面。
- 登录检查未结束时显示全站一致的加载状态，不闪现“请登录”或错误跳转。
- 未登录投稿直接进入社区登录；登录后恢复语言、产品/点子类型和产品详情中的操作位置。
- 支持、评分与评论使用一致入口；账号变化时刷新个人互动状态。
- 不改变认证方式、权限或数据库结构；原目录的未提交发帖优化不纳入本分支。

## 实现与风险

新增统一的登录回跳地址工具与加载组件，修正投稿页及顶栏的加载判定，产品互动跟随全站会话。登录页、OAuth/邮箱回调和首次资料完善共用带语言的站内回跳地址。

本批涉及会话体验与认证导航，按 AGENTS.md 启用独立 QA。保留服务端身份校验；测试仅使用本地虚构会话，不访问真实用户数据。

## 验证记录

- i18n：1249 键检查通过；未新增 UI 文案，复用全站中英文加载、登录和评论提示。
- lint 通过；生产 build/TypeScript 检查通过。
- `npm run test:auth`：10 条浏览器回归全部通过。使用本地虚构 Supabase API 与会话，覆盖游客登录后回到英文原类型、已有会话延迟不误判、支持/评分/评论入口与锚点、退出和账号切换竞态、作者自评限制、回调语言、外部回跳拦截、个人状态刷新期间不可误操作、业务资料缺失不永久加载。
- 独立 QA 初审发现的支持刷新窗口、评论状态、回调语言和业务资料缺失问题均已修复并复核，最终无本批阻塞。
- Google OAuth、真实邮箱验证、钱包授权与目标数据库均未进行真实业务验收；本地模拟不代表外部渠道已验证。

## 复现本地回归

安装项目依赖及 Google Chrome 后运行 `npm run test:auth`。测试独占 `127.0.0.1:3000` 与本地模拟 API 的 `127.0.0.1:54329`，自动启动并停止；端口占用时报错，不复用未知服务。可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定浏览器路径。测试只覆盖本地登录导航和状态交互，不使用真实凭证。
