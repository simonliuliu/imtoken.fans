## 用户反馈与实现

- 四板块取消“图标＋标题＋介绍＋发帖”大卡片，以面包屑表达当前位置，保留隐藏的语义标题。
- 首页及板块取消“参与社区”和常驻／插入式安全提醒，发帖统一保留导航栏一个入口；发帖表单中的敏感信息提示仍在操作处显示。
- 分类在第一层，推荐／最新／热门在当前分类内部生效。产品共创为全部／产品反馈／社区产品／产品公告；其他板块同构。切换分类保持排序、清除处理状态并重置分页；处理状态仅在产品反馈显示。
- 没有侧栏内容的钱包安全、产品共创、活动改为单列；首页和综合交流保留已有数字币人入口。
- 新建 [通用设计规则](../design/design-rules.md)，关联 AGENTS、工作流、Brief 和 Claude 角色配置。调用脚本每次将规则全文加入提示，缺失或为空时停止。
