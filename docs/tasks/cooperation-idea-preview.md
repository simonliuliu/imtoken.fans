## 最新输入

## 本批交付边界

- 独立示例数据和 React 本地状态；刷新恢复，不连接真实提交/评论/投票 Actions、不发 XP。
- 提交、查找、筛选排序、IDEA 与评论投票、评论回复、Admin 演示编辑/标记、状态进展、人工合并预览与撤销。
- Admin 模式是公开可体验的原型开关，不是真实账号身份或安全授权。
- 本批不实现上传、邮件/站内实际通知、客服渠道、AI、真实后台和 SQL。真实首版仍须满足原 PRD 视频上传/权限/合并撤销等要求。
- 为使原型可验证，允许限制为两个独立主帖的一层合并；必须明确提示，不宣称链式合并已完成。
