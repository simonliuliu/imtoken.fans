## 本批范围与约定

- 用户公开主页可关注/取消，默认接收该用户的新内容与新评论，可分别关闭；公开展示聚合数量与最多 100 个关注账号，私人订阅开关仅本人读取。登录前返回原主页，不自动代用户关注。
- 真实产品/点子及反馈公开发布时通知关注者；内容作者、父评论作者、被 @ 者及关注者接收新评论，按事件和收件人去重，直接回复优先，不通知本人。
- 首次审核通过才发送。重复编辑、重新公开、取消关注后新事件，以及清空后恢复均不重放；不推送迁移前历史内容，含曾发布后进回收站的内容。
- 已隐藏/删除/未审核的目标同时从消息列表、total、unread 中排除；用户和管理员遵循相同公开投影，不在 detail 缓存原文。
- 提供桌面/手机统一铃铛和分页通知中心，保留旧系统奖励类型及旧通知行。分页目标能打开相应产品/反馈与评论。
- 本批不发关注 XP，不连接虚拟帖/演示互动，不提供站外邮件、系统 Push 或 AI 消息。反馈状态更新、合并/撤销通知为后续闭环，不宣称已完整覆盖。
