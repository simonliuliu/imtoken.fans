# 论坛回复分页与通知定位

日期：2026-11-04（Asia/Singapore）。任务分支 `codex/forum-reply-pagination`，基线 `main@bc869e2`；归入 USR-01 / MSG-01。

## 问题与范围

- 回复每页显示 10 条。删除末页唯一回复后，原页码可能超过总页数，导致仍然存在的回复不显示，分页入口也消失。
- 删除前面的回复后，通知锚点应按仍可见回复的位置计算页数，才能定位到正确回复。
- 从旧回复通知进入后，再发送新回复时，已有锚点不应因回复列表刷新而反复抢回原页。

本批只调整共享评论组件的分页状态与锚点处理，不改数据库、权限、通知目标或面向用户的文案。发送和删除仍由原有服务端操作负责。
