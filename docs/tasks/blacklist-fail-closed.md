# 限制状态查询失败时阻止写入

日期：2026-11-05（Asia/Singapore）。基线 `origin/main@bc869e2`，分支 `codex/blacklist-check-fail-closed`。本批属于 ADM-02 治理与权限修复，不依赖新的数据库迁移；论坛反馈、审核一致性和回复分页仍分别沿用 PR #41、#42、#43。

## 已复现的问题与范围

用户标签查询返回错误时，原检查只读取 data，把空值当成未受限制。签到和抽奖随后使用服务端特权客户端调用数据库函数，而这些函数自身不检查黑名单。依赖替身已复现：一个已登录且实际受限的用户，在标签读取失败、随后活动 RPC 正常的条件下可能执行自己的签到或抽奖。没有验证真实用户曾遇到此问题，也不涉及冒用其他用户。

本批将查询结果区分为已限制、未限制和查询不可用；只有确认未限制才能继续。查询不可用时，签到、抽奖、评论、社区产品投稿、支持与评分返回各自已有的失败提示，不报告账号已被限制，不创建写入客户端或触发后续写操作。正常与确认为限制的行为保持原样。不会修改角色权限、数据库迁移、历史内容、通知或用户数据。
