# 登录页精简

日期：2026-11-06（Asia/Singapore）。基线：`origin/main@50b83de`。分支：`codex/login-page-simplify`；[PR #46](https://github.com/simonliuliu/imtoken.fans/pull/46)。

## 用户反馈与范围

用户在线上反馈：登录页过于复杂，希望只保留登录部分，整体设计简单清爽，不堆砌无意义的解释文字。两张参考图分别展示现有页面和希望保留的登录区域；该反馈优先进入现有论坛任务队列。

本批移除宣传侧栏和副标题，登录表单居中；保留 Google、邮箱/用户名、注册、钱包和扫码连接的现有入口与处理逻辑，以及回跳、错误、加载和社区规则。密码旁保留简洁的社区密码及钱包敏感信息提醒。账号切换状态和动态错误/成功提示补充无障碍语义，窄屏输入字号防止系统自动放大；修复隔离界面测试发现的 320px 顶部品牌区溢出。不改变认证接口、权限或数据，不执行数据库迁移。

通用设计规则补充：文案以完成当前操作所需信息、校验与安全提示为主，不以宣传或解释卡片填充页面。未对其他页面开展额外改版。

## 设计与分工

- 用户界面选择：Terra Max（用户指定，用于程序优化、实现与整合）；当前接口未提供底层运行型号或实际推理强度，不据自述推断。
- 沿用既有 Claude 设计渠道，请求 `devin/claude-opus-5-5` / `low`，附两张用户截图及通用设计规则，一次调用完成；返回用量 17,004 输入、2,365 输出 token。渠道接受请求不等于独立核验底层路由。设计建议沿用现有表单，移除宣传区，并在密码旁放一句安全提醒；不扩展认证交互。
- 独立 QA：按认证页面风险检查入口、回跳、安全文案和无障碍语义，不使用生产账号或数据库。
