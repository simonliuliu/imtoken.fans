# 产品共创信息流与统一发布

2026-10-16 · 当前状态：实现、工程检查与浏览器复核完成；待用户 review。

## 本批要求与实现

- 全部、产品反馈、社区产品、产品公告共用分类栏和推荐／最新／热门排序；分类在前、排序在后，切换保留排序。
- 反馈和社区产品只呈现信息流，移除大介绍卡、独有发布按钮和重复筛选。真实反馈详情／支持／评论／管理、真实产品详情保持。
- 全站导航统一为「发布」，均进入 `/submit`；同一页面选择普通帖子／产品反馈／社区产品后显示各自表单。旧 `/submit?type=idea` 兼容。
- 切换常规分类保留各自输入、预览、请求 ID 与上传状态；账户变化仍清理组件状态。登录返回反馈时，仅反馈表单消费反馈草稿。
- 用户未授权的新公告发布能力不在本次新增；保持现有管理业务权限。

## 分工与验证

主调度负责统一发布和整合；统一开发负责信息流；独立 QA 复核真实反馈与产品表单、草稿账户隔离。无额外 Claude 请求。本批没有迁移、真实发布或上传写入。

独立 QA 曾发现类型切换卸载请求、隐藏表单抢先消费登录草稿、旧想法与产品同时覆盖草稿，均已修复并复核。账户隔离、匿名登录接续、一次消费和 requestId 保留的内存测试通过。

## 边界

- 产品和反馈沿用真实服务；普通帖子仍为本地预览，不发 XP。公告信息流仍含原演示数据。
- 全部暂按反馈、产品、公告分组展示，每组采用同一排序，不宣称全类型混排。
- 产品尚无人工推荐字段，推荐显示明确空态；反馈仅展示已有 featured 标记，使用现有分页 RPC 读取后筛选，数据增长后宜补服务端过滤。
- 真实登录返回、真实发布、上传与角色业务本轮未实跑，不以静态审查代替业务验收。
- 原桌面目录未提交的交互继承工作保留，本批从最新主线独立 worktree 实现，不把旧版本覆盖回主线。
