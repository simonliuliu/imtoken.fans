## 用户要求与交付

用户明确指定 tokenfans 使用 **4000** 启动，覆盖旧的 3000 项目约定。保留 bman 的 3000，不停止或修改其服务。

- `npm run dev` / `npm run start` 显式监听 `127.0.0.1:4000`。
- VS Code、Claude 启动配置、Playwright baseURL/服务 URL、mock CORS、测试回跳断言统一 4000。
- `.env.local` 只改 `NEXT_PUBLIC_SITE_URL=http://localhost:4000`，三项 Supabase 配置、钱包签名密钥和其他配置保留。
- Supabase Auth site URL 和 localhost / 127.0.0.1 回调统一为 4000；保留数据停止/重启后，从实际运行容器中仅提取目标两个配置项核对。
- metadata 和 Auth 无环境配置时的本地回退地址同步为 4000。没有更改来源协议/重定向校验算法。
- 当前约定写入 AGENTS.md、README 与本地开发说明；历史 review 中的旧端口记录保留。
- Next.js 开发服务保持运行，地址 `http://localhost:4000/zh`；本地进程元数据和日志位于 `.git/local-supabase-task/`，不提交日志或凭证。

- 浏览器公开注册真实临时邮箱账号，自动 profile 与欢迎页正常；退出后通过 UI 重新登录成功。
- 浏览器对示例帖点赞并发布标记明确的测试评论；刷新后仍显示 1 赞 / 1 评论。
- 主调度通过真实 Supabase API 核对该用户的点赞及评论记录，并用独立匿名客户端读回该已发布评论。
- 测试后浏览器退出登录，精确清理测试账号、评论、点赞、经验、通知事件；迁移示例内容保留。保留匿名首页标签供用户查看。
- `npm run test:db:local` 再次 11 项通过；`npm run lint`、`npm run check-i18n`（1576 键）、`npm run build` 通过。构建保留既有的外部锁文件与 `maxWidth: none` 非阻塞提示。
- 代码、工具配置和测试中的端口/URL 检索未发现功能性的 3000 残留；没有替换 3000 毫秒的延时常量或 Docker 容器内部端口。
- 独立静态 QA 针对端口、回调及配置一致性复核 **OK / No issues found**；确认未改认证/会话/回跳校验算法，未误改 3000 毫秒延时、数值常量、mock 后端端口和容器内部端口。运行态证据来自主调度，见 [QA 记录](../reviews/local-supabase.md)。

## 风险

| 风险 | 可能性 | 缓解 |
| --- | --- | --- |
| 前后端与登录回调端口不一致 | 本批已验证 | 配置同步，运行态 Auth 环境值与浏览器登录均确认 |
| 测试误写远端或破坏示例 | 低 | 严格限制本机 Supabase，按本次用户/内容 ID 清理 |
| mock 回归测试抢占真实服务 | 已识别 | 不对运行中的 4000 执行会启动 mock 的配置 |

核心原则：网页、登录来源和真实数据库必须在同一套本地配置下运行，并用刷新后仍存在的数据证明可用。
