本批基于用户提供的 Canny Demo 和 IDEA 需求，保留现有社区视觉。交付仅为本地交互原型；公开的 Admin 演示切换不代表获得真实权限，数据/编辑/投票/合并不会写入账号或数据库，刷新恢复示例。真实上传、通知、授权和跨用户持久化需下一阶段。

## 体验顺序

1. 浏览产品反馈 IDEA，搜索并切换模块、状态和排序。
2. 填写一个相似 IDEA，查看已有候选，选择支持已有或继续提交。
3. 进入 IDEA，支持/取消、评论与回复，再给评论投票。
4. 切换 Admin 演示，编辑与标记 IDEA、评论；检查修改标识。
5. 选择同质 IDEA，核对最早主帖、支持人数去重、评论来源，再确认合并。
6. 合并后投票/取消和新增评论，撤销合并，核对保留情况。
7. 查看进展视图，以及社区产品和产品公告入口。

## Review 边界

重点确认用户流程、信息密度和管理动作。原型通过后，接真实账号、服务端业务权限与RLS、迁移、上传和通知；按仓库要求启用相应独立风险QA。数据库中同质合并需事务、并发锁、可追溯及撤销，不照搬前端演示状态实现。
