# FB-03 私有暂存基础：独立安全检查

2026-11-11，独立 QA 在本机临时 PostgreSQL/模拟 Storage 和虚构文件上审查，不读取正式库、真实附件或凭证。检查对象为候选迁移 `0035_feedback_media_staging.sql`、文件检查器及清理程序；本批没有用户界面和已部署功能。

初次复核发现：视频容器可伪造尺寸、损坏编码包可通过仅解析元数据的检查、客户端声明大小不足以限制暂存占用、事务开始时间不能用于判断实际租约到期。修复后，独立复测确认：

- 实际 4096×2304 但容器声明 16×16 的 H.264 文件、编码数据清零的视频均被受限解码拒绝；正常 H.264 MP4 和 VP9 WebM 可通过本机可信解码器。未配置解码器时拒绝视频。
- 图片/视频使用不同私有桶，互相及向既有公开桶写入被拒绝；跨草稿一字节图片预约按每桶最大容量计入 60 MiB 未关联额度，取消但未清理不立即释放。
- 事务开始后才过期的验证租约不可提交；新租约使旧令牌失效。
- 清理领取仅限服务角色和未关联到期对象，延迟覆盖已知签名及续传期限；失效令牌、存在对象时完成、跨桶或无关路径删除均被拒绝。失败与不确定响应保留重试。

验证结果：隔离数据库 14 项、文件检查 7 项、清理脚本 3 项；另以独立攻击夹具复测上述问题。构造数据和输出位于本机临时目录 `/private/tmp/feedback-media-review.8A8TJB`，不属于真实用户证据。

未验证：实际 Supabase Storage 的容量、签名/TUS/RLS 语义，真实上传竞争与故障、部署环境中的解码器与资源隔离、附件关联和审核、隐藏及合并访问、客户端播放。现有解析和子进程限制不等同操作系统级隔离；这些事项完成前不能将本批接入线上上传或称 FB-03 已验收。
