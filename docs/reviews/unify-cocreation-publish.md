# 产品共创与统一发布复核

2026-10-16。基于最新主线的独立分支 `codex/unify-cocreation-publish`。待用户 review，不自动合并或发布。

## 实现

产品反馈、社区产品、产品公告共用分类栏与推荐／最新／热门，分类先于排序，切换保留排序。移除反馈探索器和产品介绍卡、独有发布按钮及冗余筛选。导航统一「发布」，进入 `/submit` 选择普通帖子、产品反馈、社区产品；表单保持各自字段和业务。

真实产品列表保留详情链接、作者、发布时间、支持、评论、评分；真实反馈保留详情、支持、评论与管理员整理。普通帖子仍为本地预览，不写库、不发 XP。反馈附件上传仍未接入，本轮不宣称视频首版验收。

## 实际检查

- `npm run check-i18n`：1453 键通过；`npm run lint`：无错误／警告；`npm run build`：生产编译、TypeScript 和路由构建通过。
- 初次构建遇到共享依赖 symlink 越出 Turbopack 根目录，改用本地复制依赖；主仓库依赖缺 `@playwright/test`，从已有主线工作目录复制同版本测试依赖后完成构建。未修改锁文件或全局配置。
- 浏览器在本批生产构建、localhost:3000 实测：三个分类栏和排序栏 Y 坐标完全一致（135.59、187.09）；每个页面只有一个导航发布入口；没有旧产品介绍卡；热门切换分类后保留；社区产品推荐显示明确空态。
- 中文桌面和中英 390px 手机：列表和发布页无页面横向溢出；长英文分类可在分类栏内横向滚动。
- 发布页实测本地帖预览、切换反馈／产品再切回、反馈正文保留、普通帖预览保留。游客选择社区产品显示登录，链接保留语言与 `type=product` 返回地址。
- 截图复核发现从弹窗提取的表单缺少独立页样式，已补齐标签、输入框、间距，并重新验证截图。
- 独立 QA 检查真实反馈 owner/sessionEpoch/回包隔离、普通帖演示隔离、产品媒体归属与审核调用；内存实跑反馈草稿的账号隔离、匿名登录接续、一次消费、requestId 保留通过。发现并复核修复：切换类型卸载请求、隐藏普通帖抢先消费反馈草稿、旧想法与产品同时覆盖草稿。
- 本轮未进行真实登录、入库发布或上传，不以静态／内存检查替代真实角色业务验收。旧认证自动化断言依赖旧类型卡和游客自动跳转，未将其报告为通过。

## 限制

全部暂按反馈、产品、公告分组，各组使用同一排序；未做跨类型混排。产品模型没有推荐字段，推荐为空态；反馈推荐只按既有 featured，使用现有分页读取后筛选，数据增长时需要服务端过滤优化。公告保留原演示数据。原工作目录的未提交工作完整保留，当前 localhost 服务指向本批独立工作目录。
