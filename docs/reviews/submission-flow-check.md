# 发布表单补充检查

2026-10-16，继续 PR #27（`codex/community-real-interactions`）。用户反馈普通帖子没有提交按钮，同时要求检查其他提交功能。

## 根因与本批修复

当前 main 的普通发帖页仍只有“预览内容”，不会提交。PR #27 的真实帖子链路尚未合入，不能把数据库已激活等同于页面已经更新。本批继续完善该 PR，不覆盖主目录另一个任务的登录/钱包改动。

| 表单 | 修复与检查范围 |
| --- | --- |
| 普通帖子 | 保留可填写表单，底部明确“提交帖子”或“登录后提交”；说明标题/正文要求；展示提交中与失败结果；草稿及请求ID在登录交接/刷新重试时保留，服务端校验当前账户；旧入口保留合法板块参数 |
| 产品反馈（Bug/建议） | 可见登录/提交入口和长度提示；异常解除忙碌；按内容复用请求ID并在请求前保存草稿，失败不清空内容，切账号不接收旧结果 |
| 社区产品 | 必填缺项摘要；网络/服务异常后恢复按钮并保留草稿；同表单双击锁；会话失效可返回登录；成功清除本次产品草稿并保留历史idea；媒体异常就地提示，删除失败保留路径 |
