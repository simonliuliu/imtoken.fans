## 已实现

| 场景 | 新行为 |
| --- | --- |
| 关注用户 | 公开主页关注/取消，默认订阅公开发帖和评论回复，可分别关闭；本人账户校验、禁止自关注、重复请求幂等 |
| 谁收到评论 | 内容作者、父评论作者、被 @ 者和订阅该作者的人；同事件同收件人一条，直接回复优先，不通知自己 |
| 审核与恢复 | 首次公开才发，人工/AI 后续审核同样触发；不回灌历史，不因编辑、清空后恢复或旧回收站恢复再次发送 |
| 真实反馈 | 新反馈/评论事件复用同一分发，链接支持合并来源及第 50 条之后评论，站内切换目标会重新加载 |
| 消息入口 | 桌面与手机统一铃铛，独立分页通知中心，30 秒轮询，服务端全量未读，单条/全部已读和清空 |
| 隐藏与切号 | 非公开目标同时从列表/总数/未读排除；RPC 仅本人，切换账号迟到响应丢弃，失败操作不冒充成功 |
| 旧通知兼容 | 保留旧行/四类系统奖励及 detail，补漏执行 enum；DB-first 过渡期旧评论 after 插入被抑制，不重复发送 |
